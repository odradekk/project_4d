# 新的家区域

[场景标注](scene-authoring.md) · [家的区域](home-region.md) · [街道的区域](street-region.md)

`game/regions/compound.tscn` 是按 Decision note: 2026-10-29-home-scene-layout 重做的家区域，有整个小区：16 栋楼、路、小道、宅间路、杨树、围栏和大门，以及大门外的人行道、公交站和报刊亭。还没有场景用它，第 1、7、8、9 场仍用[家的区域](home-region.md)里的 `home.tscn` 和 `room.tscn`；城市布景、能开关的门和可活动范围的边界由之后的工单加上。区域只有截面Ⅰ（W = 0），棱镜关闭。16 栋楼都是 W −0.5 到 0.5 的楼房，路、杨树、围栏和大门外的东西都是截面Ⅰ的固定物件，所以小区只在截面Ⅰ里存在；它在截面Ⅱ、Ⅲ里是什么样子，留给第 8、9 场的决定。调试入口是 `-- --start=compound`，玩家出生在小满家门厅 (0.75, 3.22, 6.7)，面朝北。

坐标照白模原型（分支 `prototype/home-layout` 的 `prototypes/home-layout/index.html`），墙的位置按中线；x 向东，z 向南，y 向上，单位米。原点在小满家北墙和厨房西墙中线的交点；y = 0 是一楼地面，层高 3.2，小满家在 2 层，地面 y = 3.2；室外地面 y = −0.2。

## 楼

| 部分 | 位置 |
|---|---|
| 小满家 | x 0–7.85，z 0–7.35；阳台在 x 7.85–9.2，z 0–4.0。房间、门窗和家具见笔记「户型」一节 |
| 共用小门厅 | x 0–1.8，z 7.35–9.05。公共门在西墙 z 7.75–8.65，是敞开的门洞 |
| 邻居家 | z 9.05–16.4，和小满家以小门厅为轴镜像 |
| 楼梯间 | z 16.4–20.65，西头平台 x −1.72–1.39。往东上的一跑在北半边（z 16.52–18.47），x 1.39–6.33；转弯平台 x 6.33–7.73；往西上的一跑在南半边（z 18.59–20.53）。一楼的平台一直铺到楼梯底下；往西上那一跑底下，x = 5 处有一道隔墙，高到踏步底面，墙西边留着一块能走进去的空地，墙东边太矮、人会卡住，所以封死。一楼西侧整面敞开，是楼的出口 |
| 另一半楼 | z 20.65–37.05，和前一半以 z = 18.525 镜像 |
| 露天公走廊 | x −1.72–0，栏杆在 x = −1.72；走廊两头 z = 0 和 37.05 处也有栏杆 |

- 玩家上不了台阶，所以每跑楼梯上盖一块看不见的斜坡（和[街道的区域](street-region.md)的斜坡同理），坡面经过各级踏步的前沿，约 16.7°；一楼出口外也有一块，从平台边上的 y = 0 降到 0.75 米外的地面。斜坡是 `Props` 里的普通 `StaticBody3D`，引擎不知道它们。
- 栏杆是一根扶手加一块半透明的板，高 1.1 米，整块都挡人。
- 顶层两跑之间没有墙，原型只在楼梯口拦了一道栏杆（x = 1.39）。这里沿下面那道墙的墙顶（z = 18.525，x 1.39–6.33）又加了一道：墙顶和顶层地面一样高，不加栏杆，人站在下楼那一跑最上面几级，往北走就能跨上墙顶，掉进楼梯井。

## 文件

子场景在 `game/regions/compound/` 下，除了 `compound.tscn` 本身，都由同一目录下的 `generate.py` 按原型的常量写出（`tscn.py` 是它用来写场景文本的函数）：改格局时改脚本里的常量，再运行 `python game/regions/compound/generate.py`；直接在编辑器里改这些子场景，下次运行脚本时会被覆盖。

| 文件 | 内容 |
|---|---|
| `buildings.tscn` | 区域的 `Buildings`：16 栋楼，每栋是 `buildings/building_<列>_<排>.tscn` 的一个实例，放在楼的原点 |
| `buildings/building_<列>_<排>.tscn` | 一栋楼（`Building3D`）：下面几个共用子场景的实例，各层放在各自的高度，并给每个楼房元素改成这栋楼自己的 `EntityId` 和 `BuildingId`。小满家这栋的元素用原来的名字（`Floor0North` 等），其他楼加上列和排（`Floor0North_1_2`） |
| `north.tscn`、`south.tscn` | 一层的北半边和南半边：两户、小门厅、楼板和走廊栏杆，南半边和北半边镜像。住户只有外墙，入户门是关死的门板 |
| `flat.tscn`、`floor1_north.tscn` | 只有小满家这栋用：2 层的小满家（墙和各房间的地面，入户门和房间门都是敞开的门洞），和 2 层北半边除了小满家以外的部分 |
| `stair.tscn` | `Floor0Stair`、`Floor1Stair`、`Floor2Stair`：每层楼梯间的平台、东西墙、踏步和转弯平台 |
| `roof.tscn` | `Roof`：屋顶 |
| `site.tscn` | 截面Ⅰ的固定物件 `ground`、`roads`、`paths`、`fence`（含门柱）、`sidewalk`、`bus_stop`、`kiosk` |
| `poplar.tscn`、`poplars.tscn` | 一棵杨树，和 99 棵杨树的实例（`poplar_1` 到 `poplar_99`），也是截面Ⅰ的固定物件 |
| `furniture.tscn` | 截面Ⅰ的固定物件：`stove`、`piano`、`sofa`、`tea_table`、`father_bed`、`tv_stand`，以及占位的 `bed`、`desk`、`wardrobe`、`basin`、`squat_toilet` |
| `slopes.tscn`、`props.tscn` | 一栋楼的楼梯斜坡；截面Ⅰ的 `Props`：每栋楼一份 `slopes.tscn`，加上人行道的两块斜坡 |

## 检查

`game/tests/compound_checks.tscn` 用移动键走：

- 从小满家门厅出门，经共用小门厅、露天公走廊和楼梯走到 3 层，再下到一楼、从楼梯间西侧走出楼；途中核对走廊栏杆、顶层楼梯口和两跑之间的栏杆、邻居家的入户门都挡得住人，一楼楼梯底下能走进去，走到隔墙为止，再走出来。
- 沿小道走到西边的路，朝西走会被围栏挡住；沿路走到去大门的路，在人行道北端以北朝东走会被围栏挡住；出大门，沿人行道走进公交站的候车亭。
- 其余 15 栋楼，各从一楼楼梯间西侧的出口出发，沿小道或宅间路走到通往大门的路上。
- 小满家东边那栋楼，走楼梯上到 2 层，朝北边那户的入户门走会被挡住：这栋楼在小满家的位置上是一户普通住户。

这些路走得长，检查在走小区的部分把 `Engine.TimeScale` 调到 8，整个检查约 80 秒。区域载入约 4 秒；区域里约 9000 个盒子零件，几乎都在 16 栋楼里。
