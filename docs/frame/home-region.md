# 家的区域

[场景标注](scene-authoring.md) · [装置搭法](device-authoring.md) · [角色搭法](character-authoring.md)

`game/regions/home.tscn` 是序章第 1、7 场（日常）和第 8、9 场（小满的房间）共用的区域，格式见[场景标注](scene-authoring.md)。楼房元素、固定物件和道具分成 `game/regions/home/` 下的几个子场景，每个文件都在大小限制以内；盒子零件的模板是 `game/regions/box_part.tscn`。本页不是契约，只写第 8、9 场要遵守的限制和留给它们的位置；具体坐标以场景为准，编辑器里调整过就以调整后的为准。

坐标：x 向东，z 向南，y 向上，单位米。

## 截面和楼房

| 项目 | 取值 |
|---|---|
| 截面Ⅰ、Ⅱ、Ⅲ 的 W | 0、0.42、1.60（间距 0.42 和 1.18） |
| 楼一 `home` | W −0.5 到 0.9，包住整个家。在Ⅰ之前留 0.5，在Ⅱ之后留 0.48，逗猫棒（有效伸出 0.46）向正反两个方向竖起都装得下 |
| 楼二 `deep` | W 1.3 到 1.9，只有截面Ⅲ的那间大房间 |
| 两栋楼之间 | W 0.9 到 1.3 留空 |
| 塌洞 `FloorPit` | W 缺口 0.3 到 0.6。截面Ⅱ（0.42）在缺口里，截面Ⅰ在缺口外。皮球的最低点在 W = 0.21，在缺口外，由完好的楼板托住 |

截面里有什么：

- 截面Ⅰ：家具齐全，小满房间的门是敞开的。
- 截面Ⅱ：楼一的墙、地板、窗和吊柜外壳；没有任何家具；门被 `DoorShut` 关死；地板正中有塌洞。
- 截面Ⅲ：另一栋楼的大房间，比房间宽敞，有门 `DeepDoor` 和多出来的 `DeepDoorExtra`。窗外是发光的 `skypanel`，房间里有两盏粉金色的灯（`Sections/Ⅲ/Props`）。

## 留给第 8、9 场

小满的房间在 x 3.0–7.6、z 2.5–6.0，天花板下沿高 3.0，门在南墙 x 3.4–4.3。

- 吊柜：外壳是楼房元素 `Cabinet`，x 3.25–4.45，y 2.0–2.4，z 5.55–6.0。铰链高 2.0，天花板 3.0，翻板和长木板按[装置搭法](device-authoring.md)放。吊柜在南墙，铰链沿世界 X 轴；装置搭法里「铰链沿 Z」是测试房间的方向，装置的 Pose 要转 90°。照原型（`archives/threejs-demo/src/prologue/world.js`），长木板在吊柜旁沿铰链方向偏约 1.1 米，坡脚约在 (4.95, 4.62)，紧挨塌洞的南沿。
- 塌洞：x 4.4–5.5，z 3.95–4.5。这里没有挡板：怎样不让玩家掉进洞，由第 8 场定。
- 窗台：`Fittings` 里的窗台 x 4.95–6.25，y 0.98–1.03，z 2.5–2.76。窗台上的逗猫棒和窗台内侧的防护栏（栏杆平面 z ≈ 2.76）由第 8 场放。
- 书桌和衣柜之间的墙角：x 5.6–7.5、z 3.85–4.75、高 0.05–1.4 的范围，在截面Ⅰ和Ⅱ里都没有东西。接缝建议放在约 (7.1, 4.3)，出入口的净空两端都满足。
- 猫钻圈的下限见[角色搭法](character-authoring.md)：圈前圈后各 0.75 米没有障碍。猫从 1.2、1.0、0.8、0.6 米里挑最长且路线上没有东西的一段，两边跳的距离相同；东墙在 x 7.6，圆环平面在 x ≤ 6.48 时 1.0 米以上的跳法都没被挡住，起跳点会落在塌洞上方。所以圆环中心的 z 在 3.85 到 4.6 之间时，圆环平面放在 x 6.49 到 6.85；也可以让圆环中心的 z 避开洞的范围。
- 前门 `FrontDoor` 对引擎是敞开的，只卡剧情进度。
- `DeepWalls` 是一整个楼房元素。第 9 场要一块块啃掉墙角、窗框，第 9 场的实现得先把它拆开。
- 没有放的东西：逗猫棒、凳子、皮球、螺母、呼啦圈、接缝，以及截面Ⅲ里的接缝位置。

## 道具和灯光

- 玩家按 E 用的东西是 `Interactable3D`，灯光是 `OmniLight3D`，都放在所属 Section 下的 `Props` 里；适配层把它们移进该截面的世界。
- `Interactable3D` 在第 3 层（`collision_layer = 4`，`PhysicsLayers.Pickups`）：准星看得到，玩家和角色撞不到。要挡路的前门同时在第 1、3 层（`collision_layer = 5`）。
- 第 1、7 场是 `HomeMorning`、`HomeEvening`（`game/flow/`），做完时发 `Finished` 信号。两场都关掉棱镜，用适配层的默认光照。调试入口是 `-- --start=home-morning` 和 `-- --start=home-evening`。
- 角色在客厅、厨房、卫生间和小满房间之间走，要经过各自的门，路径点见 `game/flow/HomeRoute.cs`。
