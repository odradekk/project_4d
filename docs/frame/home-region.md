# 家的区域

[场景标注](scene-authoring.md) · [装置搭法](device-authoring.md) · [角色搭法](character-authoring.md)

`game/regions/home.tscn` 是序章第 1、7 场（日常）和第 8、9 场（小满的房间）共用的区域。格式见[场景标注](scene-authoring.md)。本页写这个区域特有的数值，以及留给第 8、9 场的位置。场景由 `game/regions/home/` 下的几个子场景拼成：楼房元素、固定物件、道具各一个文件，文件大小有限制。

## 坐标

x 向东，z 向南，y 向上，单位米。墙厚 0.2，天花板下沿高 3.0。

| 地方 | 范围 |
|---|---|
| 小满的房间 | x 3.0–7.6，z 2.5–6.0 |
| 父亲的房间 | x 7.8–10.6，z 2.5–6.0 |
| 客厅（兼饭厅） | x 3.0–10.6，z 6.2–8.8 |
| 厨房 | x 3.0–7.0，z 9.0–10.4 |
| 卫生间 | x 7.2–10.6，z 9.0–10.4 |
| 楼道 | x 0.8–2.8，z 2.3–10.6 |

小满房间的门在南墙，x 3.4–4.3，开向客厅。前门在客厅西墙，z 7.0–7.9，开向楼道。下楼的门在楼道南端（1.8, 10.6）。截面Ⅲ的房间是另一栋楼：x 0.5–9.5，z 0.5–7.5，高 4.2，包住小满房间的位置。

## 截面和楼房

| 项目 | 取值 |
|---|---|
| 截面Ⅰ、Ⅱ、Ⅲ 的 W | 0、0.42、1.60（间距 0.42 和 1.18） |
| 楼一 `home` | W −0.5 到 0.9：整个家。在Ⅰ之前留 0.5，在Ⅱ之后留 0.48，逗猫棒（有效伸出 0.46）向正反两个方向竖起都装得下 |
| 楼二 `deep` | W 1.3 到 1.9：只有截面Ⅲ的那间大房间 |
| 两栋楼之间 | W 0.9 到 1.3 留空 |
| 塌洞 `FloorPit` | x 4.4–5.5，z 3.95–4.5，W 缺口 0.3 到 0.6。截面Ⅱ（0.42）在缺口里，截面Ⅰ在缺口外。皮球的最低点在 W = 0.21，在缺口外，由完好的楼板托住 |
| 墙纸 | `RoomWallsA`（W −0.5 到 0.21）是Ⅰ的暖色，`RoomWallsB`（0.21 到 0.9）是Ⅱ的淡色。换色的 W 在两个截面之间 |

截面里有什么：

- 截面Ⅰ：家具齐全，小满房间的门是敞开的。
- 截面Ⅱ：楼一的墙、地板、窗和吊柜外壳；没有任何家具；门被 `DoorShut` 关死；地板正中有塌洞，洞口立着一块看不见的挡板 `PitGuard`，玩家和猫都进不了洞。
- 截面Ⅲ：另一栋楼的大房间，有门 `DeepDoor` 和多出来的 `DeepDoorExtra`。窗外是发光的 `skypanel`，房间里有两盏粉金色的灯。

## 留给第 8、9 场

- 吊柜：外壳是楼房元素 `Cabinet`，x 3.25–4.45，y 2.0–2.4，z 5.55–6.0。铰链高 2.0，天花板 3.0，翻板和长木板按[装置搭法](device-authoring.md)放。
- 窗台：`Fittings` 里的窗台 x 4.95–6.25，y 0.98–1.03，z 2.5–2.76。窗台上的逗猫棒和窗台内侧的防护栏（栏杆平面 z ≈ 2.76）由第 8 场放。
- 书桌和衣柜之间的墙角：x 5.6–7.5、z 3.85–4.75、高 0.05–1.4 的范围，在截面Ⅰ和Ⅱ里都没有东西。接缝出入口的净空、猫钻圈的助跑，以及圈后的墙面到圆环平面的距离，都用这块地方。
- 猫钻圈的下限见[角色搭法](character-authoring.md)：圈前圈后各 0.75 米没有障碍。截面Ⅱ里圆环轴线沿 x 时，圆环平面放在 x 6.25 到 6.85 之间：圈前到塌洞挡板（x 5.5）、圈后到东墙（x 7.6）都够 0.75 米。轴线沿 z 时，南北两面墙离 z 4.3 都有 1.7 米以上，不受限制。
- 逗猫棒、凳子、皮球、螺母、呼啦圈这些物品没有放。截面Ⅲ里接缝的位置也没有定。

## 道具和灯光

- 玩家按 E 用的东西是 `Interactable3D`，灯光是 `OmniLight3D`，都放在所属 Section 下的 `Props` 里。适配层不读 `Props`。`game/flow/HomeScene.cs` 在区域载入后把它们移进该截面的世界，这样它们只出现在这个截面里，玩家穿缝后也不会带着它们走。
- 碰撞层 4 只给准星看，玩家和角色撞不到。要挡路的（前门）用层 5。
- 第 1、7 场是 `HomeMorning`、`HomeEvening`（`game/flow/`），做完时发 `Finished` 信号。两场都关掉棱镜。调试入口是 `-- --start=home-morning` 和 `-- --start=home-evening`。
- 角色在客厅、厨房、卫生间和小满房间之间走，要经过各自的门，路径点见 `game/flow/HomeRoute.cs`。
