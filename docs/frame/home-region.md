# 家的区域

[场景标注](scene-authoring.md) · [装置搭法](device-authoring.md) · [角色搭法](character-authoring.md)

`game/regions/home.tscn` 是序章第 1、7 场（日常）用的区域；第 8、9 场（小满的房间）用继承它的 `game/regions/room.tscn`，格式见[场景标注](scene-authoring.md)。楼房元素、固定物件和道具分成 `game/regions/home/` 下的几个子场景，每个文件都在大小限制以内；盒子零件的模板是 `game/regions/box_part.tscn`。本页不是契约，只写第 8、9 场要遵守的限制和留给它们的位置；具体坐标以场景为准，编辑器里调整过就以调整后的为准。

坐标：x 向东，z 向南，y 向上，单位米。

## 截面和楼房

| 项目 | 取值 |
|---|---|
| 截面Ⅰ、Ⅱ、Ⅲ 的 W | 0、0.42、1.60（间距 0.42 和 1.18） |
| 楼一 `home` | W −0.5 到 0.9，包住整个家。在Ⅰ之前留 0.5，在Ⅱ之后留 0.48，逗猫棒（有效伸出 0.46）向正反两个方向竖起都装得下 |
| 楼二 `deep` | W 1.3 到 1.9，只有截面Ⅲ的那间大房间 |
| 两栋楼之间 | W 0.9 到 1.3 留空 |
| 塌洞 `FloorPit` | W 缺口 0.3 到 0.6。截面Ⅱ（0.42）在缺口里，截面Ⅰ在缺口外。皮球的最低点在 W = 0.21，在缺口外，由完好的楼板托住 |

截面里有什么：

- 截面Ⅰ：家具齐全，小满房间的门是敞开的。
- 截面Ⅱ：楼一的墙、地板、窗和吊柜外壳；没有任何家具；门被 `DoorShut` 关死；地板正中有塌洞。
- 截面Ⅲ：另一栋楼的大房间，比房间宽敞，有门 `DeepDoor` 和多出来的 `DeepDoorExtra`。窗外是发光的 `skypanel`，房间里有两盏粉金色的灯（`Sections/Ⅲ/Props`）。

## 留给第 8、9 场

小满的房间在 x 3.0–7.6、z 2.5–6.0，天花板下沿高 3.0，门在南墙 x 3.4–4.3。

- 吊柜：外壳是楼房元素 `Cabinet`，x 3.25–4.45，y 2.0–2.4，z 5.55–6.0。铰链高 2.0，天花板 3.0，翻板和长木板按[装置搭法](device-authoring.md)放。吊柜在南墙，铰链沿世界 X 轴；装置搭法里「铰链沿 Z」是测试房间的方向，装置的 Pose 要转 90°。照原型（`archives/threejs-demo/src/prologue/world.js`），长木板在吊柜旁沿铰链方向偏约 1.1 米，坡脚约在 (4.95, 4.62)，紧挨塌洞的南沿。
- 塌洞：x 4.4–5.5，z 3.95–4.5。这里没有挡板：怎样不让玩家掉进洞，由第 8 场定。
- 窗台：`Fittings` 里的窗台 x 4.95–6.25，y 0.98–1.03，z 2.5–2.76。窗台上的逗猫棒和窗台内侧的防护栏（栏杆平面 z ≈ 2.76）由第 8 场放。
- 书桌和衣柜之间的墙角：x 5.6–7.5、z 3.85–4.75、高 0.05–1.4 的范围，在截面Ⅰ和Ⅱ里都没有东西。接缝建议放在约 (7.1, 4.3)，出入口的净空两端都满足。
- 猫钻圈的下限见[角色搭法](character-authoring.md)：圈前圈后各 0.75 米没有障碍。猫从 1.2、1.0、0.8、0.6 米里挑最长且路线上没有东西的一段，两边跳的距离相同；东墙在 x 7.6，圆环平面在 x ≤ 6.48 时 1.0 米以上的跳法都没被挡住，起跳点会落在塌洞上方。所以圆环中心的 z 在 3.85 到 4.6 之间时，圆环平面放在 x 6.5 到 6.85；也可以让圆环中心的 z 避开洞的范围。
- 前门 `FrontDoor` 对引擎是敞开的，只卡剧情进度。
- `DeepWalls` 是一整个楼房元素。第 9 场要一块块啃掉墙角、窗框，第 9 场的实现得先把它拆开。
- 第 8 场放的东西不在 `home.tscn` 里，见本页末尾「第 8 场放的东西」。

## 道具和灯光

- 玩家按 E 用的东西是 `Interactable3D`，灯光是 `OmniLight3D`，都放在所属 Section 下的 `Props` 里。`Props` 里放普通 Godot 节点；适配层的节点放进去照样会被读成四维数据。区域载入后适配层把 `Props` 移进该截面自己的世界，用 `Region3D.Props(截面)` 取；所有区域通用。编辑器里只显示最接近 `PreviewW` 的截面的 `Props`，隐藏的状态会存进场景，载入时适配层把它们重新显示。
- `Interactable3D` 在第 3 层（`collision_layer = 4`，`PhysicsLayers.Pickups`）：准星看得到，玩家和角色撞不到。要挡路的前门同时在第 1、3 层（`collision_layer = 5`）。
- 第 1、7 场是 `HomeMorning`、`HomeEvening`（`game/flow/`），做完时发 `Finished` 信号。两场都关掉棱镜，用适配层的默认光照。调试入口是 `-- --start=home-morning` 和 `-- --start=home-evening`。
- 角色在客厅、厨房、卫生间和小满房间之间走，要经过各自的门，路径点见 `game/flow/HomeRoute.cs`。

## 第 8 场放的东西

`game/regions/room.tscn` 继承 `home.tscn`，加上第 8 场的物件；第 1、7 场仍用 `home.tscn`，所以日常段落里没有这些东西，第 9 场接着用 `room.tscn`。物件分在 `game/regions/room/` 的子场景里：`turnables.tscn`、`items.tscn`、`cabinet.tscn`、`fittings.tscn` 和预期操作 `operations.tscn`。场景脚本是 `game/flow/CatRoom.cs`，调试入口是 `-- --start=cat-room`。

|---|---|
| 逗猫棒 `wand` | 窗台上 (5.25, 1.09, 2.63)，沿 X 躺着，总长 0.48，铰链内缩 0.02。零件 `stick` 和 `yarn`：毛线球 0.1×0.12×0.12，竖起后在 W 0.36–0.46，被截面Ⅱ切到 |
| 防护栏 `guard` | 截面Ⅰ的固定物，z 2.745–2.775，栏杆宽 0.016、间距 0.1，毛线球比缝隙宽。两端各有一块端板（x 4.92–4.95 和 6.25–6.28，z 2.5–2.775，y 1.03–2.3），手里的逗猫棒走不出窗台的两头。它只在截面Ⅰ，翻面时逗猫棒在 W 方向最多摆出 ±0.13，碰不到它 |

| 接缝 `s1` | (7.1, 0, 4.3)，连截面Ⅰ、Ⅱ，在书桌和衣柜之间 |
| 接缝 `s2` | (6.25, 0, 4.3)，连截面Ⅱ、Ⅲ，镜像缝，在猫钻圈的助跑线上，离 s1 0.85 米。它不经过截面Ⅰ，所以从截面Ⅰ的镜片里看不到 |

预期操作（`room/operations.tscn`，格式见[场景标注](scene-authoring.md)）：逗猫棒翻面、手里的逗猫棒竖起、吊柜打开、螺母在书桌和衣柜之间竖起，贴墙竖起被拒绝（`RotationBlocked`），穿缝空手和拿着逗猫棒。`wand-flip` 只核对引擎接受这次翻面，翻到栏杆哪一侧由 `RoomFlowChecks` 核对。`RoomChecks` 把其中两个步骤改成相反的结果，区域就载入失败。

脚本里的约定：

- 圆环要立在猫的助跑线上：猫沿圆环中心线起跳，s2 在这条线上才进得去，所以圆环中心的 z 在 4.15–4.45（s2 在 z=4.3，猫的通行半径 0.15），平面在 x 6.5–6.85。圆环偏了，猫钻过圈也进不了缝；钻两次没进缝，小满会说「圈得立在缝跟前」。
- 猫和小满在不同截面时，抱起猫的命令马上结束：`Cat` 的抱起只在同一截面里有效。
- 小满的手最高够到脚上方 1.9 米，吊柜翻板下沿在 2.0 米，要踩凳子。凳子用空格键站上去和下来（游戏没有跳）。
- 塌洞没有挡板。掉到地面以下 3 米，就回到半秒前站着的地方；猫掉下去也一样。
- 皮球「悬在洞口」由通用查询回答：球静止且 `FindSupport` 托得住它，截面Ⅱ里球正下方的薄盒子（`QueryOccupancy`）里没有东西。
- 猫在吊柜顶、木板和塌洞边的路线点是 `CatRoom.cs` 里的常量。挪动吊柜、木板或塌洞，要同步改这些常量。
