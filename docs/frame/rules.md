# 跨截面规则与尺寸规范

[框架目录](README.md)

## 跨截面规则

| 内容 | 是否跨截面 | 具体规则 | 原型状态 |
|---|---|---|---|
| 视线 | 只能透过棱镜 | 每次只能观察一个目标截面，用滚轮切换；接缝只在镜片画面内显示。镜片画面和主画面一样跟随观察者的手性：观察者是镜像时一起左右翻转（已定） | 已实现 |
| 光线 | 不跨截面 | 每个截面只被该截面自己的光源照亮 | 已实现 |
| 声音 | 跨截面，随距离变闷 | 声源方向保持不变；来自其他截面的声音会降低音量并滤除高频，按 W 方向距离连续变闷，相隔越远越闷（已定）。同截面与相邻截面之间必须拉开明显的听感差距，确保玩家能清楚分辨声音究竟发自当前页还是隔壁页 | 部分实现：原型仅区分“同截面”与“其他截面”两档 |
| 时间 | 全局共享 | 所有截面的时间流速同步一致 | 已实现 |
| 空间联动 | 只通过贯穿物传递 | 竖起的物件、四维装置、四维物品在各个截面里都是同一个四维整体，动其一处，各处切片同步运动 | 已验证 |
| 共享量 | 按机关规则同步 | 例如“在这边放水，那边水位跟着下降”：将水位定义为一个跨截面共享的数值，由机关规则更新；各个截面实时渲染容器在该水位高度下的精确截面（已定）。之所以不按四维容器的真实几何体积计算水量，是因为我们这层世界的物品在 W 方向只有 1.2 厘米厚，里面那点水倒进真正的四维容器里体积几乎为零 | 尚未实装 |
| 支撑 | 按精确四维几何 | 物体停在它四维形体下方最高的有效支撑面上，无论该支撑面属于哪个截面都算数 | 已验证 |
| 转动碰撞 | 按精确四维几何 | 在竖起、放倒、翻面动作开始前，完整预检整段旋转过程；一旦途中会发生碰撞便拒绝启动，并通过棱镜预览标出扫过的受阻范围 | 已验证 |
| 平移碰撞 | 按精确四维几何 | 带着具有 W 厚度的物体平移时执行检测（已定），包括抓着竖起物体的切面走动、抱着四维球走动。平放在手里的普通物件完全处于角色当前截面内，无需额外做四维检测。平移受阻时沿障碍物表面滑开（X 轴与 Z 轴分量分开尝试），播放刮擦音效，并在棱镜镜片内标出碰撞点位置；玩家可随时松手离开 | 尚未实装，原型未做平移检测 |
| 换截面 | 只能通过接缝 | 穿缝时双手握持棱镜，只能携带背包内的小物件（上限 x 件，见 [gameplay.md](../gameplay.md)「食物与背包」）；大件物品、竖起的物体、四维对称物均无法带过接缝。长度够得到目标截面的可竖起物件会自动卡在缝口竖起，铰链留在出发截面。操作：举着棱镜站到开启的缝前，按左键穿缝；数字键 1–4 把背包里对应格的东西取到手里。白模阶段背包 4 格，写成一个常量，试玩后再调 | 已实现 |
| 啃食者的距离 | 跨截面，靠音乐预警 | 背景音乐按玩家与啃食者之间的四维距离（含 W 方向）实时分层变化，当它还在深层截面里时就能从音乐中听出逼近；画面闪烁作为辅助提示 | 已按四维距离驱动，音乐分层尚未细化 |
| 放倒 | 只能在原截面执行 | 竖起的物体只能在当初将它竖起的那个截面放倒，不能当成跨页传送工具 | 已实现 |
| 手性 | 由四维旋转矩阵算出 | 镜像状态不单独存储；食物消化、钥匙开锁、反写文字阅读等效果均基于手性判定。人和猫同样存储四维旋转矩阵（已定）。随身物品随角色一起穿过镜像缝并同步翻转；食物必须与进食者的手性一致才能消化 | 物件已按旋转计算，角色在原型中仍用单独开关 |

## 尺寸规范

| 项目 | 规范要求 | 序章原型取值 |
|---|---|---|
| 人造物与生物的 W 厚度 | 正负两侧各 ε | ε = 6 毫米，总厚度 1.2 厘米 |
| 截面数量与相邻截面 W 间距 Δ | 作为区域级关卡参数：每个区域按谜题需求单独设置，全作不做统一规定，间距也不必均匀。下表凡提及 Δ 处，均指所在区域的实际截面间距 | Ⅰ 到 Ⅱ 为 0.42 米，Ⅱ 到 Ⅲ 为 1.18 米 |
| 可转物件的长度 | 实际铰链到末端的有效伸出长度决定能伸入哪些截面，同时每个零件端面距截面须至少 2 厘米；不能仅用物品总长与 Δ 比较 | 逗猫棒总长 0.48 米，铰链内缩 0.02 米时有效伸出 0.46 米，仍可伸入相隔 0.42 米的Ⅱ；螺母本体长 0.06 米 |
| 零件边界与截面的距离 | 物体竖起后，各个零件的端面距任何截面（包括原截面）的距离都不得小于 2 厘米；铰链内缩至少 2 厘米，保持统一安全间距（2026-10-26 用户已定） | 原型早期竹棍端面恰好落在铰链上，竖起后原截面正好切在端面上，浮点误差导致该切片丢失；原型后来内缩 ε 仅避免切在端面，仍不符合正式的 2 厘米安全间距，不得沿用 |
| 楼房的 W 范围 | 向 +W 与 −W 两个方向延伸的余量，都必须至少超出该楼房内最长可转物品的长度（确保物品向正反两个方向都能正常竖起），同时还要包住所有隐藏四维结构的活动范围 | 楼一：W 从 −0.2 到 0.9；楼二：从 1.3 到 1.9（序章原型只允许向 +W 竖起，因此 −W 侧仅留了 0.2 米） |
| 楼与楼之间的间隔 | 一栋楼内的任何物品竖起后，绝不能碰到相邻的另一栋楼 | W 从 0.9 到 1.3 之间为完全留空区域 |
| 缺口（如塌洞） | 必须明确标注缺口的 W 区间，并核对相关四维物品的四维最低点落在缺口边缘的哪一侧 | 塌洞 W 区间为 0.3 到 0.6，皮球最低点在 W = 0.21，因此仍被完好楼板托住 |
| 四维球 | 当四维球心置于两截面之间时，两截面切出的球体一样大；其四维最低点同样位于两截面之间，放在平地上时各截面内的球体底面会悬空离地 R − r | R = 0.25，球心位于 W = 0.21，截面半径 r = 0.136，悬空离地 0.114 米 |
| 藏着的四维结构 | 静止状态下，隐藏结构距任何截面至少保持（自身粗细半径 + ε + 2 厘米）的安全距离；在关卡预期的摆放位置上必须能通过转动碰撞检查 | 螺母圆环管径粗 0.05 米，静止时位于 W = 0.2 处 |
| 接缝间距 | 同一截面内的任意两道接缝，间距至少 0.8 米 | 原型中为 0.71 米（偏近，正式版需拉大） |
| 碰撞容差 | 嵌入深度不超过该容差时视为“表面相贴”，不判为碰撞阻挡 | 5 毫米 |
| 碰撞检测步长 | 必须小于场景中最薄实体的厚度；旋转过程与携物平移均按此步长采样检测 | 1 厘米 |
| 翻转动画时长 | 起始头几度放慢角速度，让玩家看清物体缩离原截面的过程；动画每一帧仍严格渲染对应角度的精确截面 | 竖起 1.4 秒，放倒 1.0 秒，原地翻面 1.2 秒，绕障碍翻面 1.4 秒 |
