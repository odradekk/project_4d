# 公交车

家区域（[compound-region.md](compound-region.md)）大门外的公交站有一辆公交车。它从北街拐上大马路，进站停下，折叠门打开，等乘客上车；再关门开回机动车道，往南拐进南街。它按 Decision note: 2026-10-31-bus-commute 做出，第 1、7 场用它上下学。什么时候叫车、什么时候让车走、上下车时玩家怎么操作，由第 1、7 场的场景脚本决定，不在这一页。

公交车是截面Ⅰ `Props` 里的 `Bus`（`game/regions/compound/Bus3D.cs`，车身在同目录的 `Bus3DBody.cs`，路线在 `BusRoute.cs`）。它放在截面Ⅰ的 `Props` 里，所以只在截面Ⅰ里看得到。它是普通的 Godot 节点，引擎不知道它，也没有挡人的碰撞体：玩家走不下人行道，碰不到它。节点的 y 是自行车道的路面 −0.18，x、z 和朝向由脚本设置。

## 车身

2000 年前后国内城市常见的单层公交车白模。下表是车身自己的坐标：车头朝 +z，右侧（靠人行道一侧）是 −x，y 从地面算起。

| 部分 | 位置 |
|---|---|
| 车身 | 长 11 米（z −5.5 到 5.5），宽 2.5 米，高 3 米；车厢地板高 0.9 米，顶棚高 2.75 米 |
| 车门 | 右侧两扇折叠门：前门在前轮前面，z 3.75–4.85；中门在两轴之间，z −0.9 到 0.3。门洞从地板到 2.3 米高 |
| 车窗 | 一圈车窗在 1.3 到 2.3 米高，窗间有立柱；前挡风玻璃，后窗。玻璃半透明，从车里能看到外面 |
| 车轮 | 4 个，半径 0.45 米，前轴 z 2.9，后轴 z −2.7，车身下沿留出轮拱 |
| 线路牌 | 前挡风玻璃上方，白底红字「15路」，线路号是占位 |
| 车厢 | 左侧一排双人座，右侧在两扇门之间和中门后面是单人座，都朝前；司机座和仪表台在左前方；顶棚下两根纵向扶杆，过道边有 6 根竖杆 |
| 乘客位置 | 右侧中门正后面那个单人座上，坐着的小孩眼睛的高度，在 (−0.8, 2.02, −1.3)。从朝前往车门一侧转约 45°，略向下：车门在左下方，车窗外是人行道和小区。车停在站里时，眼睛在 (84.85, 1.84, 68.7) 左右 |

每扇门分左右两半，每半是两块门板：靠门框的一块绕门框转向车里，另一块铰在它的外沿上反向转两倍角度，外沿顺着门洞滑向门框。门全开时转 80°。

## 路线

公交车的中点沿着下面的路线走，车头顺着行驶方向。它出现和隐藏的地方都在小区的楼后面，玩家在人行道上看不到它凭空出现或消失。

| 段 | 位置 |
|---|---|
| 北街 | 从 x 20 出发，在往东开的南半边（z −26.5 到 −22）里，车身中线 z −24.25 |
| 拐上大马路 | 右转，绕 (85.875, −17.25) 走半径 7 米的四分之一圆，开进往南开的车道里靠小区的一条（x 91–94.75），车身中线 x 92.875 |
| 进站 | 车站前 40 米里，车身中线平滑移到停车位置 |
| 停车位置 | 车身中线 x 85.65，车身中点 z 70，在自行车道里；右侧在 x 84.4，离人行道边（x 84）0.4 米。前门 z 73.75–74.85，中门 z 69.1–70.3，都在候车亭（z 67–75）旁边 |
| 出站 | 车站后 40 米里，车身中线平滑移回车道 |
| 拐进南街 | 右转，绕 (85.875, 200.25) 走半径 7 米的四分之一圆，开进往西开的北半边（z 205 到 209.5），车身中线 z 207.25 |
| 隐藏 | 车身中点到 x 50。这时从人行道上看，它在小区东南角那栋楼后面 |

西侧绿化带（x 89–91）在 z 36–58 和 82–104 断开，是车身进出站时扫过绿化带的范围再各留 2 米；后一个口子包住去大门的路口（z 90–97）。口子里铺机动车道的沥青，路口那一段仍是去大门的路。口子里和口子两头 3 米内不种杨树，2 米内不立路灯，和其他路口一样。人行道、它边上看不见的墙和候车亭都不变。北街、南街路口和这两个口子写在 `City3DBay.cs`。

## 动画和接口

`Bus3D` 的状态 `State` 依次是：

| 状态 | 车在做什么 |
|---|---|
| `Away` | 不在场景里，隐藏。开场就是这个状态 |
| `Arriving` | 从北街开来：直路上最快 12 米/秒（约 43 千米/时），转弯时 7 米/秒，按 1.5 米/秒² 加速、1.8 米/秒² 减速，停在停车位置。从车站能看到它（车头过了 x 67）到门开完约 17 秒 |
| `Opening` | 两扇门同时折叠打开，1.2 秒 |
| `Waiting` | 门开着，一直等到场景脚本让它走 |
| `Closing` | 两扇门同时折叠关上，1.2 秒 |
| `Departing` | 以 1.5 米/秒² 起步，让它走 5 秒后已经离开车站 10 米以上；按上面的速度开到南街，到隐藏的地方回到 `Away` |

场景脚本用到的接口：

- `Arrive()`：从 `Away` 开始进站。不在 `Away` 时调用会抛异常。
- `Depart()`：从 `Waiting` 开始关门离站。不在 `Waiting` 时调用会抛异常。
- 信号 `Arrived`：门开完、进入 `Waiting` 时发出一次。
- 信号 `Boarding`：门开着时，玩家对着车门按 E 发出。
- `Seat(camera)`：把镜头固定在乘客位置上，跟着车走，直到 `Unseat()`。镜头还留在原来的父节点下，只是每帧被移到乘客位置。已经有镜头坐在车上时调用会抛异常。
- `Unseat()`：放开镜头，把它放回 `Seat` 之前在父节点里的位置。没有镜头坐在车上时调用会抛异常。

车在截面Ⅰ的 `Props` 里，适配层把每个截面的 `Props` 放进自己的视口，那个视口不会画到屏幕上。所以在车上新建一个 `Camera3D` 看不到东西；把玩家的 `Eyes` 移到车上，又会让玩家脚本找不到镜头。要坐车，就把玩家的镜头交给 `Seat`。

坐在车上时，场景脚本要停掉玩家转动视角和按 E：从乘客位置往前 2 米的准星能碰到开着的门洞，玩家转动视角也会和固定镜头的位置互相覆盖。

车上已经有乘客时（第 7 场），场景脚本先 `Seat`，再调用 `Arrive()`，等 `Arrived`。

每扇门有一个 `Interactable3D`，提示「上车」。它只在 `Waiting` 时放在碰撞层 4，其他时候不在任何层上，所以门没开、车不在站里时，准星找不到车门，按 E 没有反应。它从车身右侧往外伸出 0.5 米，越过人行道边上看不见的墙（x 84–84.1），否则准星会先碰到那堵墙。

## 检查

`game/tests/bus_checks.tscn` 载入家区域，叫车、让它走：

- 车不在时，在人行道上对着前门的位置按 E 没有反应。
- 车按顺序经过 `Arriving`、`Opening`、`Waiting`、`Closing`、`Departing`，回到 `Away`。它第一次出现在北街上，最后一次出现在南街上。
- 全程车身不碰城市布景里高过 5 厘米、从 3 米以下开始的盒子：人行道、绿化带、树干、路灯杆和楼都算。在大马路上拐弯和进出站之间，整车在往南的车道（x 91–98.5）里；在北街和南街上，整车在各自那一半车道里。
- 车停下时门是关着的；开门时门板逐渐折进车里；门开着以前不发 `Arrived`，开完发一次。停下后车身右侧离人行道边不超过 0.5 米，两扇门都在候车亭旁边。
- 门开着时车一直等着；在人行道上对着前门和中门按 E，提示是「上车」，各发一次 `Boarding`。正在开门、正在关门和车走了以后按 E 没有反应。
- 让车走以后把玩家的镜头交给 `Seat`：镜头一直在乘客位置上；5 秒后车离车站超过 8 米；`Unseat` 以后镜头回到原来的位置。
