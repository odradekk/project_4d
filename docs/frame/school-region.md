# 学校区域的搭法

[框架目录](README.md) · [场景标注](scene-authoring.md) · [角色搭法](character-authoring.md)

学校区域是 `game/regions/school.tscn`，序章第 3、4、5 场都在这里。目前只有第 3 场用到的一间教室。

## 截面和楼房

- 截面Ⅰ 在 W=0，截面Ⅱ 在 W=0.42。
- 楼房 `school` 的 W 范围是 −0.3 到 0.72，两端比截面各多 0.3 米。以后加进来的可转物件，最长的不能超过 0.3 米，否则先放宽这个范围。
- 墙、地面、天花板、黑板和讲台是楼房元素，在两个截面里都有，镜片里全都带发光轮廓，所以讲台并不比墙更显眼。
- 课桌、挂钟、窗外的烟囱是固定物，各截面自己摆一份：[内容分类](content.md)把家具定为 W 方向 ±ε 的固定物件，而且它们在两个截面里不一样。

## 两个截面的教室有什么不同

| | 截面Ⅰ | 截面Ⅱ |
|---|---|---|
| 人 | 老师和 47 个同学，小满坐在第 5 排靠过道的座位 | 没有人 |
| 课桌 | 48 张，椅子被人坐着，所以没有摆椅子 | 49 张，每张桌上倒扣着一把椅子；第 49 张在过道尽头 |
| 挂钟 | 九点十分 | 四点二十分 |
| 窗外的烟囱 | 3 根 | 2 根 |
| 讲台 | 一整块，高 0.2 米（`PodiumBlock`，W 到 0.21） | 两级台阶，高 0.1 米和 0.2 米（`PodiumSteps`，W 从 0.21） |

- 两个截面里 48 张课桌的位置一样，只有第 49 张是多出来的。位置在 `rows_i.tscn` 和 `rows_ii.tscn` 里各写了一份，改一个要两个一起改；`SchoolChecks` 逐张核对。`desk_ii.tscn` 继承 `desk_i.tscn`，只加了椅子的零件。
- 讲台换形的边界 W=0.21 在两个截面之间。老师写字的位置在讲台前面的地上，因为角色不会上 0.2 米的台阶。

## 座位、过道和视线

- 小满坐在第 5 排、左边那组靠过道的座位，眼睛离地 1.3 米。老师写字的位置在过道的延长线上，离这个座位约 6 米。老师的视野是 4.5 米，所以粉笔声一停，小满还有约 1.6 秒放下棱镜。
- 截面Ⅱ 里每张桌上的倒扣椅子高 1.23 米，比眼睛只低 0.07 米，会挡住远处的地面。所以讲台放在过道的延长线上，贴着黑板墙，椅子腿用细杆而不是整块板；从座位沿过道看，能看到讲台右半边的两级台阶。`SchoolChecks` 用射线检查从座位看得到三处不同和讲台，改动布局后要重新跑。
- 小满坐着不能走，只能转头和用手（`FirstPersonPlayer.Seated`）。

## 三处不同怎么认

举起棱镜，准星对着截面Ⅱ 里的实体时按 E 就记下一处。`PrismView.SeenEntity` 读出准星下的实体，`FirstPersonPlayer.LensMarks` 列出场景要找的实体，`MathClass` 按实体 ID 认：`clockII`、`deskII49`、`chimneyII1` 和 `chimneyII2`（两根烟囱算同一处）。改这些实体的 ID，要同步改 `MathClass`。

## 第 3 场结束时的状态

`MathClass` 发出 `Finished` 时：`Seated` 仍为 true，下一场要自己改回去；老师停在原地，不再巡视；棱镜已经可以用。
