# 角色的搭法

[契约入口](contract.md) · [实体数据](contract-data.md) · [场景标注](scene-authoring.md)

猫、老师、同桌和同学是三维生物，由出生点（CreatureSpawn3D）载入。出生点的 `CharacterScene` 根节点是 Character3D 的就是角色，数量不限。Character3D 是游戏层的节点，脚本在 `game/characters/`，不在 `game/adapter/`。

## 角色场景

| 节点 | 内容 |
|---|---|
| Character3D（CharacterBody3D，场景根节点） | `string DisplayName`（台词前的名字，出生点的 `DisplayName` 不空时以它为准）、`float WalkSpeed/RunSpeed`；碰撞层选第 2 层（`collision_layer = 2`），碰撞掩码选第 1 层（`collision_mask = 1`） |
| Shape（CollisionShape3D） | 必须有，胶囊形 |
| Visual（Node3D） | 必须有，装着模型，脚本用它表现坐、趴和镜像 |
| Cat、Pickup | 猫再带这两个子节点。Cat 是行为节点；Pickup 是 Interactable3D，球形，提示「抱起」，碰撞层选第 3 层（`collision_layer = 4`，位值 4），碰撞掩码为空 |
| Teacher | 老师再带这个行为子节点 |

第 2 层是角色的身体：玩家和别的角色不会撞上它，准星的射线也看不到它。第 3 层是猫用来被抱起的球，准星看得到，找接缝挡没挡住的射线看不到。

## 路线

角色没有寻路，只朝目标走直线，被挡住就沿障碍滑行。路线弯折的地方，比如绕过塌洞、上折返的楼梯，由场景脚本给出路径点：老师的 `Patrol` 按路径点走，猫的 `Follow` 接受一个把玩家位置换成当前要去的点的函数，`Chase` 的目标本来就是函数。

## 抱猫和 E 键

玩家可以抱起猫。抱着时再给猫（或它的身体）任何命令都会把猫放下，穿缝也会放下它。双臂一次只拿一样：手里有东西，或者已经抱着一只猫时，准星找不到别的猫，E 和提示都是关于手里的东西或抱着的猫；抱着猫时取不出背包里的东西。E 键依次作用于准星对着的 Interactable3D、手里的物品、抱着的猫、准星对着的物件，屏幕上的提示按同一顺序。

## 猫钻圈

`Cat.JumpThroughRing` 在跳之前沿整段弧线检测猫的身体（宽 0.2 米、高 0.35 米），布置圆环要给它留出位置：

- 圆环正对猫：猫到圆环中心的连线与圆环轴线在水平面上夹角不超过约 37°。
- 孔够大：孔的净半径（圆环大半径减管半径）不小于 0.23 米，猫的身体加上余量才过得去。
- 圈前圈后要有空地：猫最远从圈前 1.2 米起跳、落在圈后 1.2 米，圈后有墙就依次缩短到 1.0、0.8、0.6 米。最短的一跳要求圆环平面前后各 0.72 米（0.6 米，加猫的半径 0.1 米和余量 0.02 米）以内没有障碍，所以第 8 场把圆环立在紧挨墙根的接缝前时，墙面离圆环平面至少要 0.75 米，圈前也一样；少于 0.72 米猫就不跳。
- 高度：弧线最高点在圆环平面上，猫的中心与孔心等高；孔高 0.9 米时最高点的脚离地约 0.73 米。
- 圆环里或弧线上的东西会让猫不跳，引猫的毛线球要通过 `ignored` 传入。圆环自己不能忽略；不是实体的 ID 会让这一跳不成立，因为引擎拒绝这样的查询。
